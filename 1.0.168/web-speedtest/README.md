# 1.0.168 网页手动测速入口

适用于小米 AX9000 / RA70 原厂稳定版 **1.0.168**。恢复路由状态页的“重新测速”按钮，在 QoS 页将“开始测速”和“限速设置”并排显示，复用原厂上传、下载测速接口和结果弹窗。修正失败重试、Mbps → MB/s 换算，以及未配置 QoS 限速时测速结果不显示的问题。

## 使用教程

将 [enable-router-speedtest.sh](enable-router-speedtest.sh) 上传到路由器，在 root SSH 会话执行：

```sh
sh enable-router-speedtest.sh status
sh enable-router-speedtest.sh apply
```

无参数同 `apply`。已装旧布局时可直接再次 `apply`，脚本验证并复用原厂备份升级。完成后强制刷新网页：

- 路由状态页 → 点击 **互联网** → 外网带宽 → **重新测速**。
- 高级设置 → QoS 智能限速 → 最高速度设置 → **开始测速**。

点击后会实际测试上传和下载速度，并将成功测得的 Mbps 数值写入 QoS 上下行限速，保持 QoS 开关原状。QoS 页会立即显示测速结果；未配置限速时，刷新页面仍会读取已保存的测速结果。原厂的手工带宽、限速设置继续保留。安装脚本本身不会启动测速、开启 QoS、启用自动测速服务或重启路由器。

每次实际安装都会输出备份编号，原始页面保存在 `/data/router-speedtest-web-1.0.168/backup-XXXXXX/`。使用实际编号恢复：

```sh
sh enable-router-speedtest.sh restore backup-Ab12Cd
```

## 注意事项

- 仅接受指定固件的原始页面、共享脚本或本脚本修改后的内容；未知修改、错误固件和符号链接会被拒绝覆盖。替换前使用路由器原生 LuCI 模板编译器检查两份页面和共享脚本。
- 重复安装不会重复添加按钮。恢复支持原始/已开启页面的混合状态，便于处理两次文件替换之间意外断电的情况；未知的后续页面修改仍拒绝覆盖。
- 测速复用原厂 `bandwidth_test` 的 `new=1` 接口。该接口会测试上传和下载、保存带宽结果，并在测速前后调用原厂 QoS 停止/启动逻辑。应在允许带宽短暂被占用时点击。
- 原厂程序依赖较旧的外部测速节点。恢复按钮不保证节点仍可用或结果准确；失败时仍可使用手工带宽设置。
- 测速按钮与 QoS 开关独立。此工具修改两份网页模板及共享页面脚本，不改后端测速程序、网络配置或之前禁用的可选组件；升级固件可能覆盖补丁。
