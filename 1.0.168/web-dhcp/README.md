# 1.0.168 DHCP /16 地址池修复

适用于 **小米 AX9000 / RA70 原厂稳定版 1.0.168**。该版本已修复 `/24` 七参数错配，但 `/16` 的地址池数量仍反向相减，而且没有同步正确的起始偏移。例如 `10.31.1.50–10.31.2.10` 应写 `start=306, limit=217`，原厂却保留旧 start 并写 `limit=-215`。

补丁仅包装控制器的 `/16` 保存分支，按正确偏移计算数量。原厂注册、认证、读取、`/24` 保存、关闭 DHCP 和其他 API 均保留。工具模块本身不修改，不影响其他直接调用它的业务。

## 使用

上传 `fix-router-dhcp16-web.sh`，在 root SSH 会话执行：

```sh
sh fix-router-dhcp16-web.sh status
sh fix-router-dhcp16-web.sh apply
```

无参数同 `apply`。脚本校验型号、ROM 和两个原厂文件的 MD5：

| 文件 | 原始 MD5 |
| --- | --- |
| `luci/controller/api/xqnetwork.lua` | `2d636e2ac2170f519d353f506d90aad7` |
| `xiaoqiang/util/XQLanWanUtil.lua` | `ee5889a76bc7a43cd61ec5c68fbfa915` |

安装只替换控制器入口并保存备份，**不改写当前 DHCP/网络配置，不重启服务**。之后刷新 LAN 页面，在已经配置为 `255.255.0.0` 的 LAN 上重新提交期望地址池；补丁本身不会修改 LAN 掩码或修复先前写坏的配置。

`/16` 地址池必须在当前 LAN 网段内、起始不大于结束、数量 1–1000，排除网络地址和广播地址。数量从起止地址计算，不信任页面隐藏 `limit` 字段。租期为 2–2880 分钟，支持 `m` / `h`；网关与 DNS 支持有效 IPv4、留空清除，未提交的可选字段保持原值。

页面提交 `/16` 设置后会保存 UCI，重启 dnsmasq 并请求原厂设备重启；`/24` 及关闭 DHCP 的行为继续由原厂函数决定。只在允许网络短暂中断时提交设置。

## 备份与恢复

持久备份及包装入口保存在 `/data/router-dhcp16-web-fix-1.0.168/`。运行期间控制器仍加载其中的 `xqnetwork.original.lua`，**不要删除该目录**。

```sh
sh fix-router-dhcp16-web.sh restore
```

恢复仅在当前控制器与本次安装结果一致时执行，备份保留。重复安装/恢复不会重复修改；固件版本、原厂工具模块、备份或当前文件不匹配时拒绝覆盖。1.0.140 的备份目录独立，不交叉使用。

隔离验证涵盖跨第三段 `/16`、1000/1001 地址边界、连续保存、`/24` 与关闭 DHCP 原厂委托、无效输入、可选字段，以及安装器恢复和版本保护。配置写入、DNS 服务重启和设备重启均被模拟；未在运行 1.0.168 的实机上触发网络保存。
