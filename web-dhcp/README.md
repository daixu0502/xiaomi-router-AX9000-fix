# DHCP 保存后页面异常修复

`fix-router-dhcp-web.sh` 修复原厂 `/web/setting/lannetset` 页面保存 DHCP 设置后，租期、网关、DNS 等字段错误或空白、随后无法继续保存的问题。

目标固件：**小米 AX9000（RA70）原厂稳定版 1.0.140**。已在该设备导出的控制器和工具模块上核对参数错配；其他版本未验证，且仍须通过固定摘要检查。版本核对来源见[仓库固件说明](../README.md#针对的原厂固件)。

## 原因和修复范围

已核对的固件中，控制器 `setLanDhcp` 仍传入七个参数，`setLanDHCPService` 已要求九个参数：

```text
start, end, startip, endip, leasetime, ignore, router, dns1, dns2
```

旧调用把租期传入 `startip`、把网关传入租期，导致配置错位。`/16` 写入函数另有地址池减法方向错误，可能生成负数数量。

修复仅替换 DHCP 保存处理函数，保留原厂注册、认证及其他接口。支持页面中的 `255.255.255.0`（/24）与 `255.255.0.0`（/16），以及双向切换；`/16` 支持跨第三段的地址池，最多 1000 个地址。网关和 DNS 可以留空清除。

## 使用

上传脚本，在路由器 root SSH 会话执行：

```sh
sh fix-router-dhcp-web.sh status
sh fix-router-dhcp-web.sh apply
```

无参数等同于 `apply`。安装不会改写当前 DHCP/网络配置，也不会重启服务；完成后重新打开 LAN 设置页面。若登录会话过期，应先重新登录。

随后在原厂页面提交有效的 DHCP 启用配置，仍沿用原厂保存及重启流程；关闭 DHCP 则沿用原厂 dnsmasq 重启流程。安装不会猜测或恢复此前已经被错误调用覆盖的设置，应重新填写期望值。

脚本固定核对原控制器及工具模块摘要，其他版本会拒绝修改。不是适用于所有固件的通用 DHCP 配置工具。

## 备份和恢复

原控制器及本次安装结果保存在 `/data/router-dhcp-web-fix/`。安装后的控制器需加载其中的 `xqnetwork.original.lua`，**使用期间应保留整个目录**。

```sh
sh fix-router-dhcp-web.sh restore
```

若当前控制器已有其他改动，恢复会拒绝覆盖。重复安装、重复恢复均不会重复改写已匹配的内容。
