# AX9000 两版 SSH 工具共用条件

核对日期：2026-10-27。比较本地 RA70 开发版 1.0.140 和稳定版 1.0.168 原厂 ROM。

SSH 恢复工具只将启动脚本唯一 `channel=` 赋值改成 `channel="debug"`，两版产生的结果也相同：`2d6bbcc437d74b63ba022055c4e0f109`。保留 `ssh_en` 检查、原密码和配置端口。Telnet 必须已由原有硬固化入口提供；脚本不能保证升级后 Telnet 一定存在。

现代算法升级工具的原实现固定接受既有设备的 3964 配置。现增加两版相同的原厂 22 配置白名单，根据配置摘要识别并保留端口，候选服务仍只监听 `127.0.0.1:13964`。正式确认必须来自相应端口的新版 SSH 连接，并且配置须与准备阶段备份相同；120 秒未确认仍回退。未放宽为接受任意 SSH 配置。

SSH 工具已合并至仓库根目录 [ssh](../README.md)，两版目录引用同一套工具。路由器上原有 `/data/router-ssh-modern/` 等持久路径保持不变。新固化功能的模块来源和摘要见 `../modules/provenance.json`；原厂组件相同不代表漏洞或内核模块已实机验证。

1.0.140 的既有 3964 配置有真实登录记录；1.0.168 的结论来自原厂组件一致和本地临时样本测试，没有在运行 1.0.168 的设备上切换服务或验证登录。脚本仍要求型号/结构或摘要匹配，不表示任意小米路由器、任意固件或任意端口都能使用。

历史 SSH 检查覆盖恢复工具、真实启动模板、22/3964 配置、错误端口拒绝确认、配置变化拒绝切换及超时回退。合并后的回归还核对固化前备份、Flash CRC 与字段变化、模块加载失败保护和现代 SSH 共存。新增固化未部署至路由器，测试代码继续保持本地。
